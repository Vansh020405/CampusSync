🔧 Fix Signup Error

CampusSync - Email Constraint Issue

❌ Current Error

Unique constraint failed on the fields: (`email`)

This error occurs because your database has a unique constraint on the email field that doesn't allow multiple NULL values.

1

Open Supabase Dashboard

Click the button below to open your Supabase dashboard:

Open Supabase Dashboard →

Then select your project: bhwbmfgvqdaeqpxbaoyk

2

Navigate to SQL Editor

In the left sidebar, click on SQL Editor (looks like a terminal icon >_)

3

Create New Query

Click the "+ New Query" button at the top

4

Run This SQL Command

Copy and paste the following SQL command:

ALTER TABLE "Student" DROP CONSTRAINT IF EXISTS "Student_email_key";

Then click "RUN" or press Ctrl+Enter

5

Verify the Fix

Run this verification query to confirm the constraint is removed:

SELECT conname FROM pg_constraint 
WHERE conrelid = '"Student"'::regclass 
AND conname LIKE '%email%';

✅ Expected Result

The query should return no rows. This means the constraint has been successfully removed!

6

Deploy Code Changes

Now push your updated code to trigger a Vercel deployment:

git add .
git commit -m "fix: remove email unique constraint and add validation"
git push
7

Test Signup

Wait for Vercel to deploy (about 2 minutes), then test the signup on your Vercel URL!

Open Vercel Dashboard →

⚠️ Important Note

After this fix, students can sign up without providing an email. If you want to require emails, update your signup form validation.
